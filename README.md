# 닭의 목을 비틀어도 새벽은 온다

2026년 8월의 투자 기록을 위키 문서 형식으로 보여주는 Streamlit 앱.

## 실행

```
pip install -r requirements.txt
streamlit run app.py
```

## 구성

- `letter.md` — 본문 원문 (수정하면 앱에 바로 반영됨)
- `app.py` — 위키 스타일 렌더러
- `make_chart.py` / `cycle_chart.png` — 사이클 차트 생성 스크립트와 결과물

> 본 저장소의 내용은 투자 자문이 아니며, 개인의 판단 기록입니다.
